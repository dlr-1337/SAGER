Este registro separa uma **escolha de projeto** da **homologação institucional**. AE significa Assistência Estudantil; TI significa a equipe de tecnologia da instituição. Os responsáveis abaixo seguem os encaminhamentos propostos pelo PRD e precisam ser confirmados pela governança institucional. **Não há opção institucional aprovada, data de aprovação ou evidência de homologação registrada para D01–D26.** A data acima é apenas a data deste registro. Em cada linha, “pendente” indica a decisão que ainda deve ser formalizada; uma proposta técnica não a substitui.

## Como fechar uma decisão

Para cada ID, registrar nesta tabela ou em ata vinculada: **opção aprovada**, **responsável institucional nominal**, **data**, **justificativa e evidência**, **requisito afetado** e **versão do PRD**. Alterações que afetem contrato, dados ou estados devem atualizar a especificação, o modelo, os testes e o roteiro de homologação. Uma credencial disponível ou uma simulação não equivale a aprovação institucional; uma escolha de fornecedor para estudo não autoriza contratação ou tratamento de dados reais.
