## Como fechar uma decisão

Para cada ID, registrar nesta tabela ou em ata vinculada: **opção aprovada**, **responsável institucional nominal**, **data**, **justificativa e evidência**, **requisito afetado** e **versão do PRD**. Alterações que afetem contrato, dados ou estados devem atualizar a especificação, o modelo, os testes e o roteiro de homologação. Uma credencial disponível ou uma simulação não equivale a aprovação institucional; uma escolha de fornecedor para estudo não autoriza contratação ou tratamento de dados reais.
