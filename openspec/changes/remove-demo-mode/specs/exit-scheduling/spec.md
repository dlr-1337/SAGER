# Spec Delta

## REMOVED Requirements

### Requirement: Paridade na demonstração

**Reason**: O modo demonstração foi removido. Só existe o formulário de saída ligado ao servidor, e não há mais uma segunda implementação para manter igual.

**Migration**: Nenhuma ação de quem usa o sistema. As regras de sugestão, preservação e limite continuam nos demais requisitos desta capacidade. O mínimo da saída longa continua no formulário real ("Limites visíveis durante o preenchimento") e na recusa do servidor.
